# Depura — Descargas oficiales

Depura es una aplicación de escritorio para Windows que interpreta automáticamente extractos bancarios argentinos en PDF y los convierte en movimientos listos para conciliar y exportar.

**Descargá el instalador más reciente:** https://github.com/apacay/depura-descargas/releases/latest

- Instalador recomendado: `Depura_<versión>_x64-setup.exe`
- Alternativa MSI: `Depura_<versión>_x64_en-US.msi`
- Los archivos `.sig` son las firmas digitales de verificación de cada instalador.

Cuando haya una versión nueva, el instalador nuevo se instala encima en un minuto y conserva todos tus datos.

**Requisitos:** Windows 10/11 (64 bits).
